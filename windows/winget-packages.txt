# winget packages - snapshot of this machine's winget state.
#
# One package id per line, optional source as a second column (default: winget;
# msstore ids are Store product ids). install.ps1 runs
#   winget install --id <id> --exact --source <source>
# for every line that `winget export` does not already report as installed, so
# nothing here is ever upgraded, only added.
#
# Refresh with .\snapshot.ps1: new ids are appended under an Unsorted header
# for filing; ids that are no longer installed are reported, not deleted.
#
# Everything winget cannot match to a source (drivers, Store-only apps, the
# JetBrains IDEs, MATLAB, Wolfram, ParaView) is absent by construction; see
# README.md for that list.
